# darb — درب

تطبيق ملاحة للعراق على بيانات OpenStreetMap، بتوجيه صوتي عربي وبلاغات
مرور من المستخدمين.

ليس نسخة من ويز ولا يحمل شيئاً منه: بيانات ويز ملك Google وغير قابلة
للتوزيع. البيانات هنا من OpenStreetMap بترخيص ODbL، والمحرّكات مفتوحة.

### ما لم يُجرَّب — وهذي حدود صادقة لا تواضع

ثلاثة أشياء لا تُختبَر إلا بجهاز وطريق، وما عندي أيّهما:

1. **أداء الخريطة أثناء الملاحة** على جهاز حقيقي. الكاميرا المائلة
   الدوّارة أثقل شاشة في التطبيق، و60fps عليها افتراض لا قياس.
2. **دقّة السهم في جولة بالسيارة.** تنعيم الاتجاه وعتبة الخروج عن المسار
   (40م) و3 قراءات متتالية — كلها أرقام من منطق لا من طريق.
3. **بقاء الخدمة شغّالة والشاشة مقفلة** على Xiaomi و Huawei و Oppo.
   يقتلون الخدمات المقدّمة بسياسات خاصة فوق سلوك أندرويد القياسي، ولا
   يكفيها إعفاء البطارية. ما سوّينا توجيه المستخدم لإعدادات كل شركة.

وميزة واحدة مبنيّة وصامتة بطبيعتها: **الزحام الحيّ**. السلسلة كاملة
ومفحوصة (رحلة ← مطابقة على الطرق ← تجميع ← تلوين)، لكنها تحتاج كتلة
مستخدمين. العتبة `TRAFFIC_MIN_SAMPLES = 5` تمنعنا من إعلان زحام من سيارة
واقفة لإنزال راكب، وتعني أيضاً أن الميزة صامتة حتى يكبر العدد.

## التشغيل

### ١. البيانات (مرة واحدة)

```bash
cd tools
python 01_fetch_osm.py                  # العراق (~87MB) + تقليم عيّنة بغداد
python 02_build_tiles.py --full         # بلاطات — ينزّل ~1.3GB بيانات مساعدة أول مرة
python 03_build_routing_graph.py --full # رسم التوجيه في حاوية Docker
python 04_extract_pois.py --full        # قاعدة البحث
python 05_fetch_fonts.py                # خطوط الخريطة العربية
python 08_merge_overture.py --download  # +32,653 نقطة من خارج OSM
python 07_pack_assets.py iraq           # اختيار الحزمة المشحونة
```

احذف `--full` لتبني عيّنة بغداد وحدها — أسرع بكثير للتجربة.

**الحزمة المشحونة الآن: العراق كامل** (203MB → APK 193MB لـarm64). كل
محافظة تشتغل أوفلاين من أول تشغيل. `07_pack_assets.py baghdad` يرجّعها
لـ15MB إن احتجت النشر على Google Play — حدّ حزمته الأساسية 150MB.

السكربت يقطّع الحزمة قطعاً 16MB. ليس تنظيماً: `rootBundle.load` في
Flutter تحمّل الأصل كاملاً في الذاكرة قبل كتابته على القرص، و178MB تعني
انهياراً بنفاد الذاكرة على أكثر الهواتف المتوسطة.

### ٢. الباكند

```bash
cd server
docker compose up -d                        # PostGIS على 5433
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt
.venv/Scripts/python -m uvicorn app.main:app --port 8080 --reload
```

venv لا تثبيت عالمي بقصد: التثبيت العالمي كسر اعتمادات مشاريع أخرى على
جهاز التطوير فعلاً (aiogram يحتاج pydantic<2.10).

التوثيق التفاعلي على <http://localhost:8080/docs>.

### ٣. التطبيق

```bash
cd app
flutter pub get
flutter run                              # أو: flutter build apk --release --split-per-abi
```

على جهاز حقيقي بدّل `apiBase` في `lib/config.dart` من `10.0.2.2` لعنوان
جهازك في الشبكة المحلية.

**يلزم مرة واحدة على جهاز التطوير:** Flutter كان مضبوطاً على JDK 17 وبعض
الاعتمادات تطلب 21، فالبناء يسقط بعد 12 دقيقة بـ«invalid source release: 21»:

```bash
flutter config --jdk-dir="C:\Program Files\Java\jdk-21"
```

أحجام الـAPK (release، مع حزمة العراق كامل): arm64 **193MB** — وهو ما
تحتاجه أكثر الأجهزة. armeabi-v7a 188MB، x86_64 195MB. بحزمة بغداد وحدها
تنزل لـ40MB.

أول تشغيل يلصق 203MB من الأصول لملفات على القرص (sqflite ما يفتح ملفاً
داخل الـAPK)، فيأخذ عشرات الثواني ويعرض شريط تقدّم بنسبة. ويحتاج الجهاز
~400MB حرّة: 200 للتطبيق و200 للحزمة الملصوقة.

### ٤. الفحص

```bash
cd tools && python 06_smoke_test.py    # 39 فحصاً من طرف لطرف
cd tools && python -m pytest tests/    # 52 اختبار منطق وحزم
cd app   && flutter test               # 67 اختبار دارت
```

فحص السلسلة يمسك أشياء لا تظهر إلا على الجهاز: طبقة في النمط تشير لمصدر
غير موجود فتبقى فارغة، ونصّ يطلب حزمة خط غير مشحونة فيختفي، وقطعة من
سلسلة الإغلاقات مقطوعة. ولا واحد منها يرمي خطأ.

## المعمار

```
tools/     سكربتات مرقّمة تبني البيانات. config.py وحده يحمل الإعدادات
server/    FastAPI + PostGIS: البلاغات، الزحام، وسيط التوجيه
app/       Flutter + MapLibre
```

البيانات الخام والمبنية في `../darb-data/` — خارج الريبو.

### لماذا يمرّ التوجيه بالباكند

Valhalla يعرف الخريطة ولا يعرف بلاغاتنا. الباكند يحقن الإغلاقات المؤكّدة
في الطلب ويعلّق حالة الزحام على المسار، فيصل التطبيق مساراً يعرف الطريق
المغلق بطلب واحد. مجرَّب: إغلاق مؤكّد على مسار التحرير ← المنصور حوّله من
7.6 كم إلى 8.5 كم بعيداً 652 متراً عن نقطة الإغلاق.

### لماذا سيرفر HTTP داخل التطبيق

MapLibre ما يقرأ MBTiles ولا SQLite — يبي مصدراً بـURL. فنشغّل سيرفر
`shelf` على `127.0.0.1` بمنفذ عشوائي يقدّم البلاطات وملفات glyph من ملفات
محلية. هذا ما يجعل الخريطة تشتغل أوفلاين.

### كشف الطرق الناقصة من آثار المستخدمين

هذا ما يجعل خرائط ويز أغنى: ملايين السيارات ترسم عنده الطرق الجديدة.
البنية عندنا — الآثار تصل أصلاً للزحام. نفس الطلب على
`/trace_attributes` يعطينا الفجوات: الجزء من الأثر الذي لا تغطّيه أي
حافة يعني طريقاً لا تعرفه الخريطة. يُخزَّن مرشّحاً، ويرتفع عدّاده مع
كل جهاز يمرّ، وعند 4 يصير جديراً بالتحرير في OSM.

مفحوص بالاتجاهين: أثر 4 كم في صحراء غرب بغداد وُلِّد منه مرشّح، وأثر
على مسار معروف ولّد **صفر** — والثاني أهمّ، لأن كشفاً يرشّح كل طريق
يضيع الحقيقي في الضجيج.

### الخصوصية

قراءات السرعة تُرسل بلا معرّف جهاز وبلا معرّف رحلة — قطعة طريق وسرعة ووقت
فقط. ونحذف أول وآخر 300 متر من كل رحلة قبل الإرسال: أولها البيت وآخرها
الوجهة، وهما أخطر نقطتين. الرحلة الأقصر من ذلك تُحذف كاملة. مفحوص في
`06_smoke_test.py`.

## ما نعرفه عن حدود البيانات

قِسناه على ملف العراق يوم 2026-10-08:

- **البيانات ليست قديمة — هي نادرة.** ختم OSM في حزمتنا 2026-10-06، أي
  يومان. المشكلة تفاوت التغطية لا قِدَمها.
- **8% فقط من طرق العراق مسمّاة** في OSM (50,896 من 623,953). التفاوت
  حادّ: بغداد 13,141 شارعاً مسمّى، البصرة 377، الناصرية 47. فالتوجيه
  الصوتي يقول «انعطف يمين» بلا اسم شارع في أكثر الحالات خارج بغداد.
- **نقاط الاهتمام: 137,714** بعد دمج Overture Maps — 105,061 من OSM
  و32,653 من Meta وMicrosoft وFoursquare لا وجود لها في OSM إطلاقاً.
  الزيادة أكبر حيث كنّا أفقر: الرمادي +67%، كركوك +45%، الموصل +39%.
- **Overture لا تحلّ أسماء الشوارع:** طبقة طرقها 12,597 قطعة من OSM
  مقابل 6 من TomTom في رقعة بغداد — أي OSM نفسه. حلّ الشوارع في كشف
  الطرق من آثار المستخدمين والتحرير من داخل التطبيق.
- رسم التوجيه: بغداد 26.6MB، العراق كامل 255.9MB.
- مسارات بين المحافظات مجرَّبة: بغداد→البصرة 530 كم/4.6س،
  بغداد→الموصل 402 كم/4.5س، البصرة→دهوك 1022 كم/10.1س.
